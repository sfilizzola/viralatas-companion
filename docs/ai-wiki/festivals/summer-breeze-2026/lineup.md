## Seed apply (ops)

```bash
npm run seed:summer-breeze                    # dry-run destructive plan
npm run seed:summer-breeze -- --force         # full REPLACE (wipes SB picks)
npm run seed:summer-breeze -- --patch-meta    # UPDATE genre + image_url only
```
