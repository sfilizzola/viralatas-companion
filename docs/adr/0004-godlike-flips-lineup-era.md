# Godlike flips Lineup era; the seed script does not

Laptop sync updates live **Bands** from the **Lineup wiki**. **Lineup era flip** is godlike in the PWA on the **Active Festival** (online), **either direction**. Auto-flip on apply would treat filled columns as a **trusted clock**. Flipping back to **Announcement Lineup** drops trusted clocks even if old times remain. Other devices see the new era after **Festival cache version** invalidation reloads pack and catalog — not via Realtime on `festivals`.

**Rejected:** Laptop-only era; auto-flip when the script applies slots; one-way Schedule Lineup; festivals Realtime for instant era.
